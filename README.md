## Publicação no GitHub Pages

1. Utilize o repositório público `rafaelrmayer.github.io` na conta `rafaelrmayer`.
2. Coloque `index.html` e `README.md` na raiz da branch `main`.
3. Em **Settings → Pages**, configure **Deploy from a branch**, selecione `main` e `/(root)`.
4. Acompanhe a publicação em **Actions**.
5. Acesse [rafaelrmayer.github.io](https://rafaelrmayer.github.io/).

Para alterar as cores, edite as variáveis CSS em `:root` dentro de `index.html`. Antes de publicar, confira se os links dos projetos apontam para suas versões atuais.
