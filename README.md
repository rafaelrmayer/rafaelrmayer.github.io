# Portfólio — Rafael Ricardo Mayer

Site pessoal de projetos, pesquisa e publicações.

## Publicar no GitHub Pages

1. Crie um repositório público chamado exatamente `rafaelrmayer.github.io` na conta `rafaelrmayer`.
2. Envie o arquivo `index.html` para a raiz do repositório, na branch `main`.
3. Em **Settings → Pages**, selecione **Deploy from a branch**, `main` e `/(root)` e salve.
4. Acompanhe a publicação em **Actions**.
5. Quando a implantação concluir, abra https://rafaelrmayer.github.io/.

O site usa HTML e CSS no mesmo arquivo, sem dependências e sem instalação local. A publicação depende das configurações e do estado do GitHub Pages.
